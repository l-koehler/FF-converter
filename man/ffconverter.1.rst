===========
ffconverter
===========

---------------------------------------------------------
GUI application which converts files to different formats
---------------------------------------------------------

:Author: Ilias Stamatis <stamatis.iliass@gmail.com>
:Author: l-koehler <laura@fish.zip>
:Manual section: 1
:Version: 2.5.1

SYNOPSIS
========

``ffconverter`` [file...]

DESCRIPTION
===========

FF Converter is a simple graphical application which enables you to convert
audio, video, image and document files between all popular formats, using and
combining other programs. It uses ffmpeg for audio/video files, libreoffice for
document files, imagemagick for image files, pandoc for markdown files and
tar/ar/zip/squashfs-tools for various compressed files.

OPTIONS
=======

Currently ffconverter doesn't receive any options.
